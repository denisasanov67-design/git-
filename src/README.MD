# FOSSDEV Project: Автоматизация через Make

Этот репозиторий демонстрирует лучшие практики управления Python-проектом с использованием `Make` как единой точки входа. Архитектура построена по принципу **stateless**: виртуальное окружение не активируется вручную, а инструменты вызываются через явные пути, что гарантирует воспроизводимость в любой среде (CI/CD, локальная машина нового разработчика).


Все вышеперечисленные действия инкапсулированы в `Makefile`. Для начала работы достаточно одной команды:

```bash
make check
